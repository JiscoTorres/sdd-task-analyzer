# TaskAnalyzer

Módulo Python para análise de métricas de tarefas, desenvolvido
com base em uma especificação SDD (Spec-Driven Development).

## Objetivo

Calcular indicadores de conclusão, atrasos e distribuição de tarefas
por prioridade, seguindo o contrato definido em `specs/`.

## Tecnologias

- Python 3.11+
- pytest
- Git e GitHub
